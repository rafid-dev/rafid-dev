# Rafid Ahsan

Full-stack Roblox developer and programmer interested in systems, machine learning, pure mathematics, and theoretical physics.

I've been building on Roblox for over 5 years, primarily working on gameplay systems, backend architecture, UI, and VFX. Outside game development, I like building things that force me to understand the underlying systems — networking, compilers, model inference, simulation, and performance-oriented software.

I study pure mathematics independently, particularly analysis, topology, algebra, and geometry, with a long-term interest in mathematical physics.

## Projects

### [TailLaunch](https://github.com/rafid-dev/taillaunch)
A lightweight, cross-platform launcher for private Tailscale web applications.

Runs Tailscale in userspace and opens private services without requiring a system VPN, TUN adapter, or administrator access.

### [Rice](https://github.com/rafid-dev/rice)
A UCI chess engine written in C++.

Uses bitboards, alpha-beta search, NNUE evaluation, transposition tables, pruning, reductions, and other modern chess-engine techniques.
